## 2024-05-18 - Dynamic lang and title attributes
**Learning:** For browser extension HTML pages without clear titles or static `lang` attributes, setting `document.title` and `document.documentElement.lang` dynamically using `browser.i18n` ensures screen readers announce a proper localized title and use the correct pronunciation. Also, hide purely decorative nested elements within semantically labeled containers using `aria-hidden="true"`.
**Action:** Always dynamically inject the correct language using `document.documentElement.lang = browser.i18n.getUILanguage();` during script initialization and set `document.title`. Append `aria-hidden="true"` to decorative SVGs.
